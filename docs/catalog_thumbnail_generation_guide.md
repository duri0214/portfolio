# カタログサムネイル作成ガイド

HOME のカタログと詳細ページで使うサムネイルを生成するための資料です。画像そのものの生成・保存は、この資料を GPT に渡したユーザーが行います。

## 共通仕様

| 項目 | 指定 |
| --- | --- |
| 保存先 | `home/static/home/images/` |
| ファイル名 | 各カタログの `<slug>.png` |
| 推奨サイズ | 1200 × 675 px（16:9、PNG） |
| 表現 | 横長のフラット寄りデジタルイラスト。カード一覧でも主題が判別できる、余白のある構図。 |

### 共通プロンプト

各個別プロンプトの末尾に、次を加えて生成する。

> 横長16:9のポートフォリオ用サムネイル、1200×675px。洗練されたモダンなデジタルイラスト、主題を中央から左寄りに大きく配置、右側には適度な余白。人物の顔、読める文字、ロゴ、企業名、UIの細かい文字は入れない。写真の模倣、商標、著作権のあるキャラクターは使わない。情報を詰め込みすぎず、落ち着いたコントラストで小さなカードでも判別できる画面にする。

### 生成時のルール

- UI のスクリーンショット、コード、表計算の細かい文字を主役にしない。抽象化したカード、グラフ、帳票、データ粒子などで機能を示す。
- 実在人物、政治家、企業ロゴ、書影、地図サービスや生成AIサービスの固有UIを使わない。
- 「文字を画像へ入れない」を原則とする。画像内の文字は縮小時に読めず、生成崩れも起こりやすい。
- 同じ画面で多くても 3 つのモチーフに絞り、余白・配色・光源を整える。
- 保存前に PNG、横長 16:9、ファイル名、alt テキストを確認する。既存画像を置き換える場合も同じファイル名にする。

## 生成から保存まで

1. 優先対象または差し替えるカタログの個別プロンプトに共通プロンプトを続けて GPT へ渡す。
2. 生成画像が主題・配色・禁止事項・16:9を満たすことを確認する。
3. 表の `<slug>.png` で `home/static/home/images/` に保存する。
4. HOME と `/about/<slug>/` の両方で、画像と alt テキストが意図どおりか確認する。

カタログ定義（slug、ファイル名、alt）は `home/domain/valueobject/catalog.py` を正とする。新しいカタログを加える際は、先にこの資料へ1行追加してから画像を生成する。
