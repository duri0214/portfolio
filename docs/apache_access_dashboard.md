# Apache アクセス傾向の公開ダッシュボード（#987）

## 目的とデータ源

Apache ログ分析の見方を portfolio で紹介する。公開 URL は `/apache_access/`。
HOME のカタログ → `/about/apache_access/` → ダッシュボード、または共通ナビの `APACHE ACCESS` から開ける。

この実装は **固定サンプルのみ** を表示する。実ログを公開して安全か確認するためのログ構成・利用者数・運用情報が揃っていないため、実測値の公開は採用しない。
数値は公開デモ用に作成した架空の値で、実ログや #954 の管理者向け集計を加工・転記したものではない。
すべての閲覧者（管理者を含む）に同じ値を表示する。

## 公開データの契約

| 項目 | データ源 | 粒度・意味 | 表示箇所 |
| --- | --- | --- | --- |
| 対象期間 | 固定サンプルの週の開始・終了日 | 2026-08-03〜2026-09-13、JST、両端の日を含む6週間 | 出典欄・グラフ |
| 集計時刻 | 固定サンプルのメタ情報 | 2026-09-14 09:00 JST。サンプルに設定した時刻で、実ログの集計・監視時刻ではない | 「集計時刻（サンプル設定）」 |
| 週別リクエスト数 | 固定サンプル | 月〜日の週単位、整数件数。訪問者数ではない | 棒グラフ |
| 総リクエスト数 | 週別件数の合計 | 対象期間全体、47,600件 | サマリー・表の合計 |
| 応答区分別件数 | 固定サンプル | 対象期間全体の 2xx / 3xx / 4xx / 5xx。1xx はこのサンプルに含まない | 表 |
| 週数・応答区分数 | 固定サンプルの項目数 | 6週間・4区分 | サマリー |

実測値とサンプルの混在はない。グラフ・表にもサンプルと表示し、データ源、対象期間、集計時刻をその上にまとめる。閲覧時刻に合わせて日付を書き換えず、固定値であることを明示する。

## 公開しない情報と安全性の確認

| 観点 | 今回の判断 |
| --- | --- |
| 個別リクエスト | 生の IP、URL、クエリ文字列、User-Agent、ログ行をデータ構造へ持ち込まない。HTML、埋め込みデータ、ダウンロードとしても提供しない。 |
| エラー・検知情報 | 詳細なエラー文、検知条件、閾値、要注意パス、送信元別の集中度を公開しない。応答区分は架空の期間合計のみ。 |
| 管理画面の利用状況 | 管理画面・ログイン先の件数を含めず、#954 の非公開集計を参照しない。 |
| 障害・監視・対処の時刻 | 時間別・日別の内訳やメール送信履歴を持たない。公開する期間・集計時刻・件数はすべて架空で、実際の運用時刻には連動しない。 |
| URL の直指定 | 公開入口は固定サンプルの GET / HEAD のみ。データ源・ログパス・期間を指定する入力や未公開集計の取得ルートを設けない。管理者向け送信 URL は既存のスーパーユーザー限定 POST / CSRF 保護を継続する。 |
| 設定による切り替え | 公開処理は Apache / SMTP / GPT の設定を読まない。クエリや環境変数で実測値へ切り替える仕組みは設けない。 |

これにより、公開指標から実際の管理画面利用・障害発生・監視や対処のタイミングを推測するための観測値を提供しない。
将来実測値を使う場合は、この表で公開項目を改めて審査し、期間を粗くする方法と公開を遅延させる方法を決める。安全性を確認できるまでは固定サンプルを継続する。

## 実装の責務

- `lib/apache_access/domain/valueobject/public_dashboard.py`: 公開可能な日付・区分・件数だけの型。管理者向け `ApacheAccessReport` は使わない。
- `lib/apache_access/domain/service/public_dashboard.py`: 外部入力のない固定サンプルの構築。
- `lib/apache_access/public_dashboard.py`: 公開専用の値をテンプレートへ渡す薄い入口。
- `templates/apache_access/dashboard.html`: 集計値と出典・期間・サンプル表記を表示する。
- `home`: カタログと紹介ページの責務だけを持つ。

Django アプリ、モデル、migration、公開データ用の保存先は追加しない。ログ読み取り・SMTP・GPT の準備は公開デモの閲覧には不要。
#954 の専用管理画面は追加せず、管理者向け実測集計とメール送信は従来の非公開経路で扱う。既存の共通ナビにある管理者限定の送信操作を、公開指標の操作やデータ更新として扱わない。

## 検証範囲

`lib/apache_access/test_public_dashboard.py` で、公開フィールドの契約、週と合計の整合性、データ源と時点の表示、すべての権限での固定サンプル表示、入力による実データへの切り替え不可、未公開 URL の 404、非管理者の送信不可、カタログ導線を検証する。
既存の `lib/apache_access/test_report_service.py` と `home.tests` も合わせて実行し、非公開メール送信の権限・CSRF と既存カタログへの影響を確認する。
