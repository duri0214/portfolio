# Apache アクセス分析アプリ（#987）

## 目的と表示モード

`/apache_access/` で週別リクエスト件数と応答区分別件数を表示する。
HOME のカタログ → `/about/apache_access/` → アプリ、または共通ナビの `APACHE ACCESS` から開ける。

| 環境 | 閲覧者 | データ源 |
| --- | --- | --- |
| 本番（`DEBUG=False`） | ログイン済みの有効なスーパーユーザー | Apache の実ログ |
| 本番（`DEBUG=False`） | 未ログイン・一般・スタッフ | 固定サンプル |
| 開発（`DEBUG=True`） | すべての閲覧者 | 固定サンプル |

環境は既存の `DJANGO_DEBUG_MODE` から設定される `settings.DEBUG` で判定する。URL パラメータからデータ源、ログパス、期間、権限を変更する入力は設けない。
実測・サンプルを画面上で明示し、両者の値を混在させない。

## 期間と集計の意味

| 項目 | 管理者向け実測 | 公開サンプル |
| --- | --- | --- |
| データ源 | `APACHE_ACCESS_LOG_GLOBS` に一致する現行・ローテート済み・gzipログ | 実ログとは独立した架空の値 |
| 対象期間 | JSTで今週を含む6週間。5週前の月曜00:00を含み、集計時刻を含まない | 2026-08-03〜2026-09-13、両端の日を含む6週間 |
| 集計時刻 | 閲覧時の集計時刻（JST） | 固定の2026-09-14 09:00 JST（サンプル設定） |
| 週別件数 | 月〜日のリクエスト件数。今週は集計時刻まで | 6週の固定値 |
| 応答区分 | 期間全体の2xx〜5xx。1xxがあれば追加 | 2xx〜5xxの4区分 |
| 総件数 | 週別件数・応答区分別件数の合計 | 47,600件 |

件数は訪問者数ではなくリクエスト数を表す。ログの保存期間によって6週間分が揃わない場合があり、画面にもその制約を表示する。
一致したファイルは同一パスを重複排除し、一度読み取って集計する。期間外の行は集計しない。日時のオフセットを考慮し、JSTの日付で週へ振り分ける。

## 取得失敗と0件の区別

- ログがない場合は503で設定確認を案内する。
- 読み取り拒否やgzipの破損で読めない場合は503で読み取り確認を案内する。
- 解析不能行があり、期間内の有効なリクエストが0件の場合は503でログ形式確認を案内する。
- 有効な集計がある場合、解析不能行を除外して件数を表示し、除外行数も通知する。
- 空ファイルや、正常に解析できたログに対象期間の行がない場合は実測0件を表示する。

実測の取得失敗をサンプルや0件に置き換えない。例外の詳細はサーバーログへ記録し、画面には固定の案内を表示する。

## 情報の扱い

- 公開サンプルの表示では実ログを読まない。閲覧にSMTPやGPTの準備は不要。
- 実測の表示には日付、応答区分、件数だけを渡す。IP、URL、クエリ文字列、User-Agent、生ログは表示データへ含めない。
- 全モードとエラー応答に `Cache-Control: private, no-store` と `Vary: Cookie` を付け、管理者の実測値が共有キャッシュやログアウト後の画面取得に流用されるのを防ぐ。
- 表示はGET / HEADで行い、集計結果を保存しない。

## 実装の責務

| 配置 | 責務 |
| --- | --- |
| `apache_access/apps.py`、`urls.py`、`views.py` | Djangoアプリの登録、URL、環境・閲覧権限に応じた表示 |
| `apache_access/domain/service/dashboard.py` | サンプル生成、実測集計から週別表示への変換 |
| `apache_access/domain/valueobject/dashboard.py` | 画面に渡す期間・区分・件数 |
| `apache_access/templates/apache_access/` | アプリ専用のbaseとindexテンプレート。HOMEへ戻るパンくずは設けない |
| `apache_access/static/apache_access/c_a.ico` | アプリ専用favicon |
| `lib/apache_access/domain/service/` | ログ読み取りとダッシュボード用の期間集計を提供する共通ライブラリ |
| `lib/apache_access/domain/valueobject/traffic.py` | 識別子を含まない日別・応答区分別集計 |
| `home` | カタログと紹介ページ |

モデル・migrationは不要。実測閲覧に必要なログ形式、対象ファイル、Web実行ユーザーの読み取り権限は、共通ライブラリの [運用手順](../lib/apache_access/README.md) に従って確認する。

## 検証範囲

- `apache_access/tests.py`: 環境と権限の全組み合わせ、サンプルの整合性、実測の期間変換、0件・503表示、アプリの導線、favicon、ログアウトとキャッシュの境界。
- `lib/apache_access/test_traffic.py`: 現行・gzipログ、期間境界、タイムゾーン、HTTP応答区分、重複パターン、識別子の除外、ログなし・空・解析不能・読み取り失敗。
- `home.tests`: HOMEと紹介導線の回帰確認。
