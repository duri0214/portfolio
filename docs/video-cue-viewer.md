# ローカルの解析結果を閲覧する

`video_cue` は Rust エンジンの出力フォルダーを直接読む Django ビューアです。
フォルダー直下の `0001/analysis.json` のような動画別の結果を一覧化します。
JSON・MP4 のコピー、DB 登録、再解析、エンコードは行いません。

## 起動と目検

PowerShell を portfolio リポジトリで開きます。既存の `.venv` と `.env`、
スタッフ権限（`is_staff=True`）のアカウントを使用します。
指定された engine #6 の出力は次のコマンドで直接参照できます。

```powershell
Set-Location C:\Users\yoshi\OneDrive\dev\portfolio
$env:DJANGO_DEBUG_MODE = 'True'
$env:VIDEO_CUE_RESULTS_ROOT = 'C:\Users\yoshi\Downloads\video-cue-engine-batch-GnbWlr'
$env:VIDEO_CUE_SOURCE_ROOT = 'C:\Users\yoshi\OneDrive\dev\video-cue-engine\fixtures'
.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

継続して使う場合は `VIDEO_CUE_RESULTS_ROOT` と `VIDEO_CUE_SOURCE_ROOT` を
ローカルの `.env` に設定できます。元動画を接続しない場合、後者は空欄にします。
未設定の結果フォルダーには503、未完了結果には409、不正JSONには422を返します。
動画欠損の場合は説明を表示し、利用できる別の動画で閲覧します。
設定・ファイル修正後はページを再読み込みしてください。

1. `http://127.0.0.1:8000/video_cue/` を開き、スタッフアカウントでログインする。
2. `0001` を開く。3イベントの一覧と1つのハイライトプレイヤーが表示される。
3. 再生・一時停止、前／次、一覧、タイムラインの番号、シークバーを操作する。
   イベント開始位置はハイライトの `1.0 / 5.2 / 8.8` 秒。
   元動画の対応開始位置は `1.8 / 6.0 / 10.0` 秒。
4. イベント2を選び「元動画で確認」を押す。元動画の6秒へ移動する。
5. 一覧から `0002` を開く。イベント0件の説明が表示され、元動画を接続していれば再生できる。
6. ブラウザー幅を390px程度に縮め、プレイヤー、主要操作、一覧に横溢れがないことを確認する。

動画・JSON・DBの生成物はありません。元フォルダーも変更しません。
ヘッダーのアプリ選択「VIDEO CUE」からも開けます。
スタッフ以外には録画一覧・JSON由来の情報・動画を公開せず、403とログイン案内を表示します。

## 配信と時刻の制約

- `schema_version` 1/2 を扱います。旧形式にハイライトがなくても個別クリップを再生できます。
- ハイライトがない場合は元動画、元動画もない場合は個別クリップへ切り替えます。
- 元動画時刻は、ハイライトのイベント開始秒からの差分で動き区間内のみ表示します。
  JSON に連結区間の境界やクリップの前後余白がないため、余白では「区間外」、
  個別クリップでは「対応時刻なし」と表示し、推測値を正確な時刻として扱いません。
- 動画は JSON に記載された MP4 のみ。結果フォルダー内の相対参照と、明示設定した
  元動画ディレクトリ内の参照に限定し、シンボリックリンクの実体も範囲確認します。
- スタッフ認証を動画配信にも適用し、単一 byte Range（206）・HEAD・範囲外（416）に対応します。
- JSON の読み込み上限は8 MiB。フォルダー名は英数字・ハイフン・アンダースコアを使用します。
- ブラウザーで再生できるMP4が必要です。形式や通信の失敗はプレイヤーに表示します。
