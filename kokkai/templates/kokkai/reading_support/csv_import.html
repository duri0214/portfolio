辞書項目をCSVから取り込む

CSVの形式

{% if can_manage_reading_support %} CSVテンプレート（サンプル付き）をダウンロード {% else %}
スーパーユーザー権限が必要です。
{% endif %}

UTF-8のカンマ区切りCSVを使用します。従来の4列に加え、候補CSVには任意の生成モデル列が付きます。

CSV列名（画面の項目名） 入力
word（単語）必須
reading（読み）必須
description（説明）必須
source_url（出典URL）任意
generated_by_model（生成モデル）任意

取り込み時の扱い

  • 新しいwordは辞書に追加します。
  • wordだけで同じ辞書項目かを判定します。全角・半角、英字の大小文字、空白の違いは同じwordとして扱い、reading、description、source_url、generated_by_modelをCSVの値で上書きします。source_urlを空欄にすると、登録済みの出典URLも空欄になります。
  • 同じCSV内に同じwordが複数ある場合はエラーです。CSV全体を取り込まず、行を1つにまとめてから再度取り込んでください。
