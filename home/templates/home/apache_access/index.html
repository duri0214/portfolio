Apache ログ分析

アクセスの増減と HTTP 応答の内訳を、ひとつの画面で読む。

Apache のアクセスログを、週ごとのリクエスト数と応答区分の件数にまとめたダッシュボードです。

何を見るためのアプリか

アクセスログを一行ずつ追っても、サイト全体の変化はつかみにくいものです。この画面では、過去数週間の量の変化と、リクエストに対して返した応答の内訳を一緒に確認できます。

個別のアクセスを調べる画面ではなく、傾向を見つけるための入口です。

画面で確認できること

週ごとのリクエスト

月曜始まりの6週間を棒グラフで比較します。どの週にアクセスが増減したかを確認できます。実測表示では今週の件数は集計時刻までの途中経過です。

HTTP 応答の内訳

期間全体の応答を 2xx（成功）、3xx（リダイレクト）、4xx（クライアントエラー）、5xx（サーバーエラー）に分けて件数を表示します。実測で 1xx があれば、その区分も加わります。

データの出典と時点

サンプルか実測か、対象期間、集計時刻を件数の近くに表示します。固定のデモ数値を、現在のアクセス状況と取り違えないためです。

公開デモの数字を読むと

架空の6週間には合計47,600件のリクエストがあり、最後の週は9,300件です。応答の表には 2xx が42,000件、3xx が4,200件、4xx が1,200件、5xx が200件と並びます。棒グラフで週ごとの量を比べ、表で期間全体の応答を確認する使い方です。

リクエスト数は訪問者数ではありません。また、4xx や 5xx の件数だけで原因や攻撃の有無は判断できません。

表示されるデータについて

公開デモ

どなたでも開けます。2026年8月3日〜9月13日の架空の6週間を固定表示するため、実際のサイトの利用状況や稼働状況は示しません。

本番環境のスーパーユーザー

ログイン中は、読み取り可能な Apache ログから今週を含む6週間を集計した実測値を確認できます。ログの保存期間によって、過去の週の件数が揃わない場合があります。

画面に載せるのは期間ごとの件数です。IP アドレス、アクセス先の URL、クエリ文字列など、個別のアクセス情報は表示しません。

集計メールとの違い

ダッシュボードは6週間の傾向を見るための画面です。共通ナビの「アクセス集計をメール送信」は、スーパーユーザーが直近24時間の詳細な集計を受け取るための別の操作です。公開デモを開くだけでメールが送られることはありません。
