# カタログサムネイル作成ガイド

HOME の各カタログ用サムネイルを生成するための資料です。画像そのものの生成と `home/static/home/images/` への保存はユーザーが行います。

各見出しの **生成プロンプト** は、それだけで GPT に渡せる完全な文章です。複数枚を作るときも、作りたい画像のプロンプトをそれぞれ丸ごとコピーして使います。

## 共通の保存ルール

- すべて PNG、1200 × 675 px、横長 16:9 で作る。
- 見出しに示したファイル名で `home/static/home/images/` に保存する。
- alt テキストは `home/domain/valueobject/catalog.py` の定義と一致させる。
- 読める文字、ロゴ、企業名、実在人物、政治家、商標、著作権のあるキャラクター、固有サービスの UI は画像に入れない。
